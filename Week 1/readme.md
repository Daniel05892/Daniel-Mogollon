📘 Proyectos Semanales Desarrollados

Los proyectos presentados en este repositorio forman parte del proceso de formación en *desarrollo de software utilizando JavaScript moderno, enfocado en el diseño, construcción y validación de aplicaciones web interactivas bajo los principios del **Análisis y Desarrollo de Software (ADSO)*.

Cada proyecto ha sido desarrollado como un ejercicio práctico que simula el funcionamiento de un sistema real, integrando conceptos fundamentales de *análisis, diseño y programación, aplicados a un dominio específico: **Accesorios Deportivos*.

---

# 🧠 Enfoque para el análisis y desarrollo de software

Desde la perspectiva del *Análisis y Desarrollo de Software*, los proyectos abordan problemáticas comunes en sistemas digitales relacionados con la gestión de productos deportivos, tales como:

* Gestión de información estructurada de productos
* Modelado de entidades y atributos
* Representación de estados y disponibilidad de productos
* Interacción entre usuario y sistema
* Organización y separación de responsabilidades en el código
* Diseño de soluciones mantenibles y escalables

Durante el desarrollo se aplican principios fundamentales de ingeniería de software como:

* *Abstracción del dominio*
* *Separación entre lógica, datos y presentación*
* *Organización modular del código*
* *Claridad en la representación de la información*
* *Buenas prácticas en la escritura de código*

---

# 🧩 Dominio de Aplicación: Accesorios Deportivos

El dominio de *Accesorios Deportivos* representa un entorno digital donde se gestionan productos utilizados en diferentes disciplinas deportivas.

Dentro de este dominio se pueden modelar distintos escenarios como:

* Registro de productos deportivos
* Clasificación por categorías deportivas
* Gestión de disponibilidad de productos
* Cálculo de precios y descuentos
* Organización de inventarios
* Presentación estructurada de información del producto

Este dominio permite desarrollar proyectos con *una base realista, evitando implementaciones genéricas y promoviendo soluciones alineadas con sistemas de **comercio electrónico o gestión de productos deportivos*.

# ⚙️ Tecnologías y Conceptos Aplicados

Los proyectos incluidos en este repositorio han sido desarrollados utilizando tecnologías web fundamentales:

* *JavaScript ES2023*
* *Node.js*
* *HTML5 semántico*
* *CSS3*

Durante el desarrollo se aplican conceptos esenciales como:

* Uso de *tipos de datos primitivos* (string, number, boolean)

* Organización del código mediante *comentarios estructurados*
* Representación clara de información en consola
* Separación básica entre lógica y presentación
